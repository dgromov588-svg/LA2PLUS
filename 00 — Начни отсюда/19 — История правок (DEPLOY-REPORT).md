**Автоматизация (то, что просили «чтобы само»).** Никакого ручного обслуживания нет:

1. **Обновление кода установки** — `pwa.js` подключается с версией по времени правки файла
   (`?v=filemtime`), манифест и service worker отдаются с `Cache-Control: no-cache`
   (правило добавлено в `.htaccess`). Новая версия доезжает при следующем открытии сайта.
2. **Обновление иконок и офлайн-страницы** — service worker кэширует статику по принципу
   «отдать из кэша, а в фоне обновить» (stale-while-revalidate). Старые кэши удаляются на
   активации новой версии; версия поднимается заменой `VERSION` в одном файле.
3. **Повторное предложение** — если игрок отказался, предложение вернётся через 60 дней,
   а после установки исчезнет само (событие `appinstalled`).
4. **Языки и устройства** — что показывать, решает браузер игрока (`beforeinstallprompt`,
   `display-mode: standalone`, UA), сервер ничего не настраивает.

**Что пришлось обойти на этом хостинге.**

* `.htaccess` разрешает выполнять только файлы из белого списка — любой служебный PHP
  (в том числе cron-скрипт) отдаёт 403. Поэтому автоматизация сделана без cron и без PHP-скриптов:
  только версионирование по mtime, заголовки кэша и service worker.
* LiteSpeed отдаёт `.webmanifest` как `application/octet-stream` — с таким типом Chrome
  установку не предлагает. Манифест назван `manifest.json` (`application/json`).
  Побочный эффект: `AddType` для `.webmanifest` через Fileman применить не удалось —
  запись `.htaccess` обнуляет файл, поэтому правило добавлено в существующий файл точечно.
  **Внимание:** при правке `.htaccess` через Fileman файл обнуляется — проверять размер после записи.
* Fileman не пишет бинарные файлы (`save_file_content` портит байты) — иконки залиты через
  `Fileman/upload_files` с проверкой размера по HTTP.

  рядом с иконками приложения положен рабочий `design/assets/icons/favicon.ico`.
