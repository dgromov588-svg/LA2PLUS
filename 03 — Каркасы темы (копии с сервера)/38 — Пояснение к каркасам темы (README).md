# prod-layouts — раскладки темы с боевого сервера

Эти файлы **не входят в поставку**: они лежат только на сервере в
`public_html/cms-private/themes/la2plus/views/layouts/` и правятся напрямую.
Копии здесь — чтобы было с чем сравнивать и из чего восстанавливать.

| Файл | Что это |
|---|---|
| `master.php` | каркас личного кабинета. Здесь живёт переключатель «Кабинет / Админка» |
| `admin.php` | отдельный каркас админки (`body.adm`, своя навигация). Подключён: `$this->layout = '//layouts/admin'` в `PanelBaseController` и `PanelController` (15.11.2026) |
| `admin.css` | стили каркаса, боевая копия `public_html/design/css/pages/admin.css` |

## Состояние на 15.11.2026, 11:05 UTC

`master.php` — с правкой `$inPanel` (см. `DEPLOY-REPORT.md`, раздел 4а).
Резервная копия на сервере: `master.php.bak-20261115-105606`.

## Если нужно откатить переключатель

На сервере:

```
cp .../layouts/master.php.bak-20261115-105606 .../layouts/master.php
```

Признак «мы в админке» должен считаться по модулю и маршруту, а не только по
`getController()->getId() === 'panel'` — после `forward()` контроллер называется
`default` / `staff` / `users`.

## Про admin.php

С 15.11.2026 каркас подключён и работает: админка больше не рисуется внутри
игрового кабинета. Карта маршрутов внутри каркаса переписана под фактические
маршруты (`cabinet/panel/panelStaff`, `panel/staff/index` и т.д.), ветка с
`strlen('cabinet/panel/panel')` убрана — она резала путь на символ длиннее.

Если правите каркас на сервере, не забудьте перенести копию сюда: `master.php`
и `landing.php` живут только на сервере.
