## Текущая задача: устойчивое скачивание игры

Пользователь сообщил, что лаунчер 1.1.1 останавливает скачивание при сбросе TCP-соединения. В исходниках 1.2.0 это исправлено: временные сетевые ошибки и HTTP 408/425/429/5xx автоматически повторяются с задержкой, скачивание продолжается с сохранённого байта, размер одного запроса ограничен 8 МиБ, одновременно работают два потока. `Retry-After` учитывается; пауза немедленно отменяет ожидание переподключения. Повреждённый сжатый кэш повторно скачивается с нуля с ограничением числа попыток. Подпись и SHA-256 обязательны; ошибки сертификата и неверный диапазон не игнорируются.

Код: `launcher/internal/update/network.go`, `engine.go`, тесты `network_test.go`.
Базовое сетевое исправление: `c91da213a76347a617e80a090f2cd1fc764d88c7`.

## Что делать после полной проверки

1. Проверить результат Actions и файл `la2plus-full-release.json` в артефакте `LA2PLUS-Windows-Launcher`. При ошибке изучить логи и исправить причину; не выдавать выборочную проверку за полную.
2. При успехе получить **установщик именно из проверенного Windows-артефакта**, вычислить SHA-256, опубликовать `downloads/LA2PLUS-Setup-1.2.0.exe`. Существующие версионные установщики не перезаписывать.
3. Атомарно обновить `downloads/LA2PLUS-Setup.exe` и его `.sha256`, сохранив предыдущий выпуск для отката.
4. Два подготовленных файла с новыми ссылками: `implementation/public_html/design/js/config.js` и `implementation/public_html/cms-private/themes/la2plus/views/layouts/landing.php`. Сейчас они указывают на 1.2.0 только в репозитории. Перед заменой сравнить действующие файлы с резервной копией; не затирать параллельные правки владельца. Проверить скачивание через «Файлы» и «Присоединиться», размер/хеш, текущую вкладку и мобильную ширину.
5. Обновить этот документ фактическим результатом и закоммитить состояние.

## Проект и хостинг

- Основной сайт: https://la2plus.com/ ; webroot `/home/laplusco/public_html`.
- Тестовый сайт: https://new.la2plus.com/ ; webroot `/home/laplusco/new.la2plus.com`. Демобазы из тестового сайта не переносить в основной.
- Действующий исходный код сайта и overlay: `implementation/public_html/`. Метаданные — `implementation/release-manifest.json`; сборка — `python3 tools/build_portal_release.py`. Не разворачивать весь overlay без проверки состояния основного сайта.
- Нативный Windows-лаунчер: `launcher/`. Используются официальный логотип и фон главной страницы.
- Каталог `08 — Шлюзы NOWPayments и Trybit/` содержит отдельные материалы/патчи и инструкции. Незакоммиченные прежде изменения сохранены по просьбе владельца; это не означает их отдельную публикацию на хостинг.
- Ключ подписи выпуска хранится **только на хостинге вне webroot**: `/home/laplusco/launcher-private/signing-seed.txt`. Не создавать новый ключ при обычном обновлении, не включать его в Git/логи/артефакты.
- В исходном рабочем окружении приватные средства cPanel, резервные копии и результаты проверок находятся в игнорируемом `work/`. Они намеренно не отправляются в Git. Для нового окружения доступы нужно получить через защищённый канал.

## Сохранить принятые решения

Публичные логотипы — только фирменное изображение LA2PLUS. Навигация сайта открывается в текущей вкладке. В кабинете нет PIN операций, карточки персональной скидки и предложений установки Android/iOS. Переключатели разделов владельца сохраняются. Данные игроков и платёжные операции не сбрасываются при обновлении интерфейса. Не включать демоинтеграцию игровых операций на основном сайте. Готовность платёжных шлюзов и серверной доставки настраивается отдельно; изменения интерфейса не означают их включение.
