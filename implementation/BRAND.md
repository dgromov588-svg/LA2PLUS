# Фирменный логотип LA2PLUS

Основной знак для новой версии кабинета и всех дальнейших разделов — оригинальный золотой LA2PLUS с сине-фиолетовым свечением, выбранный владельцем 18 ноября 2026 года.

- Единственный исходник: `public_html/design/assets/images/logo.png` (2172 × 724, прозрачный PNG). Не подменять его текстовыми надписями LA2PLUS, LA2 или отдельными буквенными эмблемами.
- Общий компонент: `BrandLogo::html('nav')`. Для крупной декоративной позиции — `BrandLogo::html('display', true)`. В общих шаблонах доступны также варианты `header`, `hero`, `preloader`.
- Подключать `BrandLogo::STYLES` в каркасе страницы. Путь изображения, версия и доступное название хранятся в компоненте; световой блик использует маску того же файла.
- Сохранять пропорцию 3:1, прозрачность и исходные золотые/сине-фиолетовые цвета. Не растягивать, не обрезать и не добавлять непрозрачную подложку.
- Перелив выполняется через CSS поверх формы оригинального изображения. При `prefers-reduced-motion: reduce` анимация отключена. Декоративные повторы не озвучиваются экранным диктором; логотип-ссылка имеет доступное название LA2PLUS.

Изменение опубликовано на тестовом `new.la2plus.com`; исходники и правило предназначены для дальнейшего использования. Действующий основной сайт этим обновлением не заменяется.
