# LA2PLUS Windows Launcher

Нативный Windows 10/11 x64 лаунчер и установщик для игроков. Приложение не требует отдельной установки .NET или WebView. Устанавливается для текущего пользователя и создаёт ярлыки; игровые файлы скачиваются в выбранную отдельную папку. Доступны русский и английский игровые клиенты.

При первом запуске лаунчер проверяет сборку и предлагает скачать недостающие файлы. Для уже установленной сборки обновления загружаются автоматически при запуске, когда игра закрыта. Можно приостановить загрузку и продолжить позже; уже проверенные файлы сохраняются. «Проверить все файлы» выполняет полную проверку SHA-256. Настройки `system_ru/Option.ini`, `User.ini` и их английские варианты сохраняются.

## Обновления

Публичный манифест: `https://la2plus.com/launcher/stable.json`. Он подписан Ed25519; приложение содержит только открытый ключ. Приложение принимает HTTPS-ресурсы проекта, проверяет границы HTTP Range, размеры и SHA-256 каждого распакованного файла. Загрузка идёт прямо из необходимых диапазонов ZIP: повторно скачивать 13 ГБ при небольшом обновлении не нужно. За основу взята действующая сборка проекта; служебные `_backup*`, `_safe_stage`, `.bak` и старый updater исключены.

Новая версия сначала скачивается и проверяется в `.la2plus` внутри папки игры. Затем применяется с журналом и резервными копиями. После прерывания незавершённые замены восстанавливаются. Неизвестные пользовательские файлы не удаляются. Приложение не принимает игровые пароли и не хранит платёжные данные.

Первичная сборка требует около 13 ГБ трафика и около 30 ГБ свободного места. Лаунчер оценивает фактическое необходимое место перед загрузкой. Для обновления нужно закрыть игру. Удаление лаунчера сохраняет игровые файлы.

## Сборка

Go 1.27.4, NSIS 3.11. Зависимости зафиксированы в `go.mod`/`go.sum`. В Linux с Go и `makensis` в PATH:

```sh
launcher/tools/build.sh
```

Результат: `launcher/dist/LA2PLUS-Setup-1.0.1.exe` и SHA-256. Ресурсы Windows включают манифест Common Controls, поддержку DPI и официальный логотип. GitHub Actions проверяет протокол/восстановление, создаёт окно Windows, собирает установщик и проверяет установку/удаление. Установщик пока не имеет Authenticode-подписи: для подтверждённого издателя Windows нужен сертификат владельца проекта.

## Публикация следующих игровых обновлений

Закрытый seed Ed25519 хранится на хостинге вне webroot: `/home/laplusco/launcher-private/signing-seed.txt`. Его нельзя включать в репозиторий, ZIP клиента, браузерные настройки или логи. Открытый ключ находится в `internal/release/trust.go`. Генерация нового ключа требует пересборки/распространения лаунчера; при обычном обновлении ключ не меняется.

1. Загрузить новый полный ZIP сборки с **новым именем** на хостинг. Не изменять существующий архив выпуска на месте.
2. Запустить закрытый publisher (заведомо новая версия):

```sh
/home/laplusco/launcher-private/publisher-v1 \
  -archive /home/laplusco/launcher-incoming/LA2PLUS-2026.12.01.zip \
  -out /home/laplusco/public_html/launcher \
  -key /home/laplusco/launcher-private/signing-seed.txt \
  -version 2026.12.01.1 \
  -status /home/laplusco/launcher-private/progress.json
```

Publisher потоково проверит весь архив и файлы, создаст неизменяемую ссылку `releases/<version>/client.zip`, подпишет манифест и атомарно заменит `stable.json`. Данные ZIP не дублируются на диске при создании hard link. Для каждого выпуска требуется уникальная версия. Уже опубликованные архивы нельзя перезаписывать: при новом выпуске загружать новый ZIP и снова запускать publisher. Старые выпуски сохранять на время докачки игроков.

## Проверки

`go test -race ./internal/...` — подписи, недопустимые Windows-пути, границы архива, докачка, контрольные суммы, сохранение настроек и восстановление после прерывания. `go run ./cmd/smoke -folder <temporary-directory>` проверяет действующие HTTPS Range и реальные RU/EN исполняемые файлы по подписанным хешам, без запуска игры. Реальный вход персонажа проверяется на игровом сервере отдельно.
